# Проверка маскировки профиля

Чек-лист перед запуском профиля «в бой». Цель: убедиться, что подменённые поля
согласованы между собой, с легендой и с exit-IP, и что фингерпринт стабилен
между чтениями. Противоречивый или нестабильный фингерпринт детектится надёжнее,
чем вообще не тронутый.

## Правила проверки

1. Проверять только через прокси профиля. Прямое соединение ломает легенду до
   первого пункта чек-листа.
2. Каждую проверку повторять: перезагрузить страницу, перезапустить профиль,
   открыть страницу заново. Стабильность важнее самих значений — почти все
   проверялки ловят именно расхождения между повторными чтениями.
3. Сверять значения с легендой (Fingerprint из vault), а не только с «зелёными»
   индикаторами сайтов: сайты ошибаются в обе стороны.

## Сайты-проверялки

### browserleaks.com

Страницы: `/javascript`, `/canvas`, `/webgl`, `/webrtc`, `/fonts`.

- **/javascript** — UA, platform, languages, timezone, screen (width/height,
  avail\*, dpr, colorDepth), hardwareConcurrency, deviceMemory, plugins,
  webdriver. Всё должно совпадать с легендой профиля; `webdriver = false`.
- **/canvas** — хэш должен отличаться от хэша реальной машины (шум на месте) и
  быть одинаковым при повторных чтениях в этом профиле; в другом профиле —
  другим.
- **/webgl** — vendor и renderer из легенды; параметры (maxTextureSize,
  maxViewportDims, maxRenderbufferSize) из легенды; хэши стабильны между
  чтениями.
- **/webrtc** — при `webRTC = "relay"` только relay/mDNS-кандидаты, реальный IP
  не виден; при `"off"` конструктор `RTCPeerConnection` бросает TypeError (как
  при выключенном WebRTC в Chrome); при `"real"` адреса видны намеренно — это
  осознанное решение, совместимое только с прямым соединением или легендой
  «этот IP мой».
- **/fonts** — набор шрифтов должен соответствовать ОС легенды (Windows-набор
  для windows-профиля и т.д.). Закрывается нативным слоем, не JS — см. раздел
  «Сознательные отказы».

### creepjs.com

CreepJS собирает «lies» — расхождения между источниками. Смотреть:

- consistency: таймзона из `Date` против `Intl` против конфига; languages против
  UA; GPU против ОС;
- стабильность canvas/webgl/audio между загрузками страницы;
- итоговый ID: стабильный в рамках профиля, разный между профилями.

Цель: ноль lies или близко к тому.

### fingerprint.com (демо)

- Visitor ID стабилен между сессиями одного профиля.
- Разные профили дают разные ID.
- В components: canvas, audio, fonts, screen соответствуют легенде.

### pixelscan.net

Главное — вердикт Consistency: соответствие IP ↔ язык ↔ таймзона. Также смотрит
UA против platform, WebGL-хэш, признаки автоматизации. Цель: consistent, без
красных пунктов.

### iphey.com

- IP: не датацентр / не помечен как VPN там, где это важно (свойство прокси,
  не браузера).
- WebRTC: не показывает IP вне прокси.
- Браузер: язык и таймзона против гео IP, целостность фингерпринта.

### whoer.net

Построчно: IP, WebRTC (совпадает с прокси или пуст), DNS (свойство прокси),
язык, часовой пояс, экран, плагины. Итоговый балл — ориентир, решение принимать
по построчным данным. Критерий готовности волны 1: whoer не видит противоречий
в подменённых полях.

## Типовые проколы

1. **GPU против ОС.** Renderer с Direct3D11 в macos-профиле, Metal в
   windows-профиле, llvmpipe там, где заявлена дискретная карта. Валидатор
   mirage-core обязан такое отклонять (правила консистентности в
   [CONTRACT.md](CONTRACT.md)). Если противоречие видно на странице — запущен
   профиль, не прошедший валидацию.
2. **Таймзона / язык / IP-гео.** `Europe/London` + `en-US` + IP из Франкфурта —
   классический детект. Языки и таймзона в генераторе связаны с координатами
   локали; координаты должны соответствовать гео exit-IP. Ловится на pixelscan,
   iphey, whoer.
3. **Утечка WebRTC при прокси.** STUN отдаёт реальный публичный IP мимо прокси.
   С прокси использовать `webRTC = "relay"` или `"off"`. Режим `"real"` с
   прокси — осознанная дыра.
4. **Нестабильный canvas-шум.** Разные хэши при повторных чтениях — самый
   громкий сигнал (ловят fingerprint.js и CreepJS в первую очередь).
   `canvasSeed` и `audioSeed` детерминированы seed'ом профиля: одинаковый вход —
   побайтово одинаковый выход. Проверяется на browserleaks/canvas (reload) и
   creepjs.
5. **`navigator.webdriver = true`.** Признак автоматизации. Подменяется на
   `Navigator.prototype` + флаг `--disable-blink-features=AutomationControlled`.
   Проверять на browserleaks/javascript.
6. **Client Hints против UA.** UA говорит Windows 11, а `userAgentData` отдаёт
   macOS или другую мажорную версию — детект. В Mirage client hints задаются
   нативно (`Network.setUserAgentOverride` → `userAgentMetadata`) и обязаны
   совпадать с UA-строкой и brands (правило консистентности №7 в CONTRACT.md).
   Проверять: browserleaks/javascript (userAgentData), creepjs.

## Что мы сознательно не подменяем из JS и почему

- **Шрифты.** Перечисление шрифтов из JS детектится measurement-проверками:
  замер ширины глифов, `document.fonts`, `measureText` с фолбэками. Набор
  шрифтов подменяет нативный слой (`patches/`); поле `fonts` в конфиге — вход
  для него.
- **Сериализация canvas (`toDataURL` / `toBlob`).** Перехват сериализации из
  JS ломает валидность PNG или палится по артефактам. Пиксельное чтение
  (`getImageData`) шумится в JS детерминированно (canvasSeed, ~3% младших
  бит), а сериализацию закрывает нативный слой (`patches/`): тот же алгоритм
  шума, побитово портированный в C++, чтобы оба пути чтения давали
  согласованную картину.
- **`DynamicsCompressorNode`.** Подмена параметров компрессора с фильтром
  ломает реальное аудио (воспроизведение, звонки) и детектится по артефактам.
  Аудио-шум задаётся `audioSeed` в других точках аудио-стека.
- **`Date` при нативной эмуляции таймзоны.** Если CDP-команда
  `Emulation.setTimezoneOverride` уже дала нужную зону, JS-слой не трогает
  `Date` вообще: подмена Date из JS детектится. `time.js` сравнивает фактическую
  зону с конфигом и отступает при совпадении.
- **`toLocale*` на fallback-пути.** `Date.prototype.toLocaleString` и
  родственные используют внутренний интринзик движка, а не патчивое свойство
  `Intl.DateTimeFormat`: на основном пути их закрывает нативная CDP-эмуляция
  зоны, но при чисто JS-подмене времени `toLocale*` продолжили бы отдавать
  реальную зону. Оговорка задокументирована в шапке `inject/time.js`;
  практический вывод: CDP-override — основной механизм, JS — только fallback.

## Итоговый порядок перед боем

1. Профиль проходит валидацию консистентности (mirage-core).
2. Прокси поднят, exit-IP соответствует гео легенды (проверка exit-IP в
   mirage-proxy).
3. whoer / pixelscan: нет противоречий язык / таймзона / IP.
4. browserleaks: поля совпадают с легендой; canvas/webgl-хэши стабильны.
5. creepjs: нет lies; ID стабилен.
6. Повторный запуск профиля: те же поля, те же хэши.
